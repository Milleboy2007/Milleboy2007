### 🚀 Projets Principaux

* **[ScheduleFlow](https://github.com/Milleboy2007/ScheduleFlow.git)** : Application desktop de gestion d'horaires et de quarts de travail. Développée en C# (WPF) avec Entity Framework Core.
* **VanLife** : Application de location de vans camper déployée sur AWS. Infrastructure as Code avec Terraform, conteneurisation via ECS Fargate, équilibrage de charge (ALB) et base de données RDS MySQL. Repo de config terraform -> [Ici](https://github.com/Milleboy2007/final-2484435-414-vanlife-config.git)
* **Cardiaco** : Système IoT de surveillance du rythme cardiaque. Hardware basé sur Raspberry Pi et Pico W avec convertisseurs ADS1115, transmission des données via protocole UDP et interface web sous Flask. Lien: [Interface Web](https://github.com/Milleboy2007/Cardiaco.git), [Capteur](https://github.com/Milleboy2007/Cardiaco-Cap.git)
* **[Adopt your Pokemon](https://github.com/Milleboy2007/Poke-App.git)** : Plateforme full-stack d'adoption exploitant l'API PokéAPI. Développée avec React en frontend, NestJS et TypeORM en backend, avec SQLite.
